🎰 Slot Machine Game in Python
A simple command-line based Slot Machine Game built using Python. This project simulates a real slot machine where players can place bets, spin reels, and win rewards based on matching symbols.

📌 Features
🎮 Interactive command-line gameplay
💰 Betting system with balance management
🔁 Randomized slot spins
🏆 Win/Loss calculation
📊 Displays current balance

❌ Exit option anytime
🛠️ Technologies Used
Language: Python 3
Libraries: random

📂 Project Structure
slot-machine-game/
│
├── slot_machine.py
├── README.md

▶️ How to Run the Game
1️⃣ Clone the Repository
git clone https://github.com/your-username/slot-machine-game.git

2️⃣ Navigate to Project Folder
cd slot-machine-game

3️⃣ Run the Program
python slot_machine.py

Make sure Python 3 is installed on your system.

🎯 Game Rules
Player starts with an initial balance.
Choose the amount to bet.
Spin the slot machine.
If symbols match → You win!
If not → You lose the bet.

Continue playing until balance is zero or you exit.
